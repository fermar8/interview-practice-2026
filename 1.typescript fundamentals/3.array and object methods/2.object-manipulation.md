# Object Manipulation in TypeScript

## 1. `Object.assign`

Copies enumerable own properties from source objects into a target object.

```ts
const target = { a: 1, b: 2 };
const source = { b: 4, c: 5 };
const returnedTarget = Object.assign(target, source);

console.log(returnedTarget); // { a: 1, b: 4, c: 5 }
```

## 2. `Object.keys`

Returns an array of an object's own enumerable property names.

```ts
const obj = { a: 1, b: 2, c: 3 };
const keys: string[] = Object.keys(obj);
console.log(keys); // ["a", "b", "c"]
```

## 3. `Object.values`

Returns an array of an object's own enumerable values.

```ts
const values: number[] = Object.values(obj);
console.log(values); // [1, 2, 3]
```

## 4. `Object.entries`

Returns an array of key-value pairs.

```ts
const entries: [string, number][] = Object.entries(obj);
console.log(entries); // [["a", 1], ["b", 2], ["c", 3]]
```

## 5. `Object.freeze`

Prevents modifications (adding/removing/changing properties).

```ts
const frozenObj = Object.freeze({ a: 1, b: 2 });
frozenObj.a = 3;
console.log(frozenObj); // { a: 1, b: 2 }
```

A frozen object is effectively immutable at runtime.
