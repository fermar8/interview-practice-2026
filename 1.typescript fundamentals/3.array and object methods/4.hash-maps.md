# Hash Maps (Map vs Object)

## Overview
Hash maps are a data structure that allows us to store key-value pairs. They are also known as hash tables or dictionaries in other programming languages.

## Map Object
In JavaScript/TypeScript, we can use the built-in `Map` object to create a hash map:

```typescript
const myMap = new Map<string, number>();
myMap.set("one", 1);
myMap.set("two", 2);
myMap.set("three", 3);

console.log(myMap.get("two")); // Output: 2
console.log(myMap.has("three")); // Output: true
myMap.delete("one");
console.log(myMap.has("one")); // Output: false
```

## Key Characteristics of Map
- A `Map` is a collection of key-value pairs where **keys and values can be of any type**
- The `Map` object provides methods for adding, removing, and retrieving key-value pairs
- Maintains insertion order

## Map vs Object

### When to Use Map
Use `Map` when you need to:
- Maintain the order of key-value pairs
- Use keys that are not strings or symbols
- Store a large number of key-value pairs and want better performance

### Performance Benefits
`Map` is more performant for lookups and insertions because:
- Uses a hash function to compute the index of the key-value pair
- Allows for faster lookups and insertions compared to an object
- Objects use a linear search to find key-value pairs

### Hash Function
A hash function is a function that takes an input (or "key") and returns a fixed-size string of bytes. This allows `Map` to quickly locate values in its internal data structure.
