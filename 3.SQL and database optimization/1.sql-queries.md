# SQL Queries

## Overview
Understanding different types of SQL joins and their use cases.

## Inner Join
A type of join that returns **only the rows that have matching values in both tables**. It is the most common type of join.

### Use Case
Combine rows from two or more tables based on a related column between them.

### Example
```sql
SELECT Customers.CustomerName, Orders.OrderID
FROM Customers
INNER JOIN Orders ON Customers.CustomerID = Orders.CustomerID;
```

Returns all customers along with their orders (only customers who placed orders).

## Left Join (Left Outer Join)
Returns **all rows from the left table** and **matching rows from the right table**. If no match in the right table, results contain NULL values.

### Use Case
When you want to include all rows from the left table, even if there are no matches in the right table.

### Example
```sql
SELECT Customers.CustomerName, Orders.OrderID
FROM Customers
LEFT JOIN Orders ON Customers.CustomerID = Orders.CustomerID;
```

Returns all customers along with their orders. Includes customers who have not placed any orders (with NULL values for order columns).

## Rows Disappearing in Left Join
Rows don't actually disappear in a Left Join. When there are no matching rows in the right table:
- The row from the left table is still included
- The columns from the right table contain NULL values

Example:
- Customer "John" has never placed an order
- John will appear in the result set
- The `OrderID` column will contain NULL for John's row
