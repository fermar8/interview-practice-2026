# Loop Types in TypeScript

## `for` Loop

Traditional loop with initialization, condition, and increment/decrement.

```ts
const numbers2 = [1, 2, 3, 4, 5];
for (let i = 0; i < numbers2.length; i++) {
  console.log(numbers2[i]);
}
```

## `for...of` Loop

Iterates over values of iterable objects (arrays, strings, maps, sets, etc.).

```ts
for (const num of numbers2) {
  console.log(num);
}
```

## `for...in` Loop

Iterates over enumerable keys of an object.

```ts
const obj2 = { a: 1, b: 2, c: 3 };
for (const key in obj2) {
  if (obj2.hasOwnProperty("a")) {
    console.log(`${key}: ${obj2[key as keyof typeof obj2]}`);
  } else {
    console.log(`${key} is not an own property of obj2`);
  }
}
```

Note: Type assertion is used so TypeScript accepts indexed access with `key`.

## `while` Loop

Runs while condition remains true.

```ts
let count = 0;
while (count < 5) {
  console.log(count);
  count++;
}
```

## `do...while` Loop

Runs at least once before checking the condition.

```ts
let count2 = 0;
do {
  console.log(count2);
  count2++;
} while (count2 < 5);
```

## Practical Preference

- Prefer `for...of` for arrays and iterables
- Use `for...in` for object property iteration
