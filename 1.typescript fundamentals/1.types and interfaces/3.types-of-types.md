# Types of Types

## Overview
Types have more flexibility than interfaces. You can declare a type as a union or intersection of other types, or as a tuple, which you cannot do with interfaces.

## Union Types
A union type is one that can be one of several types:

```typescript
type StringOrNumber = number | string;
```

## Intersection Types
An intersection type combines multiple types, ensuring the result has all properties from both types:

```typescript
type Cat = { purrs: boolean } & { colour: string };
```

## Tuple Types
A tuple type has a fixed number of elements with specific types in each index:

```typescript
type Point = [number, number];
```
