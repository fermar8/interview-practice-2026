# Express/Fastify Structure (TypeScript)

## Goal

Use a clear project structure that separates responsibilities for maintainability and scalability.

## Suggested Layering

- `controllers`: request/response handling
- `services`: business logic
- `routes`: endpoint wiring
- `repositories`: data access
- `middleware`: cross-cutting concerns (auth, logging, etc.)
- `models`: data structures
- `index.ts`: server bootstrap

## Example Structure and Code

### `src/index.ts`

```ts
import express from "express";
import routes from "./routes";

const app = express();
app.use(express.json());
app.use("/api", routes);

app.listen(3000, () => {
  console.log("Server is running on port 3000");
});
```

### `src/routes/index.ts`

```ts
import { Router } from "express";
import userRoutes from "./userRoutes";

const router = Router();
router.use("/users", userRoutes);

export default router;
```

### `src/routes/userRoutes.ts`

```ts
import { Router } from "express";
import { getUsers, createUser } from "../controllers/userController";

const router = Router();
router.get("/", getUsers);
router.post("/", createUser);

export default router;
```

### `src/controllers/userController.ts`

```ts
import { Request, Response } from "express";
import { UserService } from "../services/userService";

const userService = new UserService();

export const getUsers = (req: Request, res: Response) => {
  const users = userService.getUsers();
  res.json(users);
};

export const createUser = (req: Request, res: Response) => {
  const user = userService.createUser(req.body);
  res.status(201).json(user);
};
```

### `src/services/userService.ts`

```ts
interface User {
  id: number;
  name: string;
  email: string;
}

class UserService {
  private users: User[] = [];

  getUsers(): User[] {
    return this.users;
  }

  createUser(userData: Omit<User, "id">): User {
    const newUser: User = {
      id: this.users.length + 1,
      ...userData,
    };
    this.users.push(newUser);
    return newUser;
  }
}

export { UserService };
```

## Production Considerations

- Add caching (for example Redis)
- Use persistent DBs (PostgreSQL/MySQL)
- Consider ORMs (TypeORM/Sequelize)
- Implement rate limiting
- Monitor DB bottlenecks and query performance
- Add tests (unit + integration, for example Jest)
