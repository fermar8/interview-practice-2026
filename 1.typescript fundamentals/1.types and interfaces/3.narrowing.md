# Type Narrowing

## Overview
Sometimes we have a value that could be one of several types. We might need narrowing to figure out which type it is in order to work with it.

## The Problem
```typescript
function padLeft(padding: number | string, input: string): string {
  return " ".repeat(padding) + input; // TS Error: padding could be string
}
```

## Type Guard Narrowing
Use a type guard to narrow the type of `padding`:

```typescript
function padLeftWorking(padding: number | string, input: string): string {
  if (typeof padding === "number") {
    return " ".repeat(padding) + input;
  }
  return padding + input;
}
```

## Truthiness Narrowing
Narrow a type based on whether a value is truthy or falsy:

```typescript
function getUsersOnlineMessage(numUsersOnline: number) {
  if (numUsersOnline) {
    return `There are ${numUsersOnline} online now!`;
  }
  return "Nobody's here. :(";
}
```

## Equality Narrowing
Narrow a type based on whether two values are equal:

```typescript
function exampleEqualityNarrowing(x: string | number, y: string | boolean) {
  if (x === y) {
    // Here, TypeScript knows that x and y must be of the same type
    // and narrows the type accordingly.
  }
}
```

## The `in` Operator Narrowing
Narrow a type based on whether a property exists in an object:

```typescript
type Fish = { swim: () => void };
type Bird = { fly: () => void };

function move(animal: Fish | Bird) {
  if ("swim" in animal) {
    return animal.swim();
  }
  return animal.fly();
}
```

## `instanceof` Operator Narrowing
Narrow a type based on whether an object is an instance of a class:

```typescript
function logValue(x: Date | string) {
  if (x instanceof Date) {
    console.log(x.toUTCString());
  } else {
    console.log(x.toUpperCase());
  }
}
```
