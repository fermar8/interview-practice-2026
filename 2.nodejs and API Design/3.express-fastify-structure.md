# Express/Fastify Project Structure

## Overview
Example of how to structure an Express or Fastify project in TypeScript.

## Directory Structure
```
src/
├── controllers/      # Handle HTTP requests and responses
├── services/         # Contain business logic
├── routes/           # Define API routes
├── index.ts          # Set up server and import routes
```

## Project Setup

### src/index.ts
Entry point where you set up your server:

```typescript
import express from "express";
import routes from "./routes";

const app = express();
app.use(express.json());
app.use("/api", routes);

app.listen(3000, () => {
  console.log("Server is running on port 3000");
});
```

### src/routes/index.ts
Router configuration:

```typescript
import { Router } from "express";
import userRoutes from "./userRoutes";

const router = Router();
router.use("/users", userRoutes);

export default router;
```

### src/routes/userRoutes.ts
Route definitions:

```typescript
import { Router } from "express";
import { getUsers, createUser } from "../controllers/userController";

const router = Router();
router.get("/", getUsers);
router.post("/", createUser);

export default router;
```

### src/controllers/userController.ts
Request/response handlers:

```typescript
import { Request, Response } from "express";
import { UserService } from "../services/userService";

const userService = new UserService();

export const getUsers = (req: Request, res: Response) => {
  const users = userService.getUsers();
  res.json(users);
};

export const createUser = (req: Request, res: Response) => {
  const user = userService.createUser(req.body);
  res.status(201).json(user);
};
```

### src/services/userService.ts
Business logic:

```typescript
interface User {
  id: number;
  name: string;
  email: string;
}

class UserService {
  private users: User[] = [];

  getUsers(): User[] {
    return this.users;
  }

  createUser(userData: Omit<User, "id">): User {
    const newUser: User = {
      id: this.users.length + 1,
      ...userData,
    };
    this.users.push(newUser);
    return newUser;
  }
}

export { UserService };
```

## Additional Considerations

### Performance Optimization
- Use **caching** to improve performance
- Use **in-memory database** like Redis for caching
- Use **relational database** like PostgreSQL or MySQL for persistent storage
- Use **ORM** library like TypeORM or Sequelize

### API Security
- Check database bottlenecks and optimize queries
- Implement **rate limiting** using libraries like `express-rate-limit`
- Ensure API can handle high volume of requests without crashing

### Testing
- Use testing framework like **Jest**
- Write **unit tests** and **integration tests**
- Catch bugs early and ensure API works as expected
