# Array and Map Practice

## 1. Deduplicating Arrays with `Set`

```ts
const array1 = [1, 2, 3, 4, 5];
const array2 = [3, 4, 5, 6, 7];

const deduplicatedArray = Array.from(new Set([...array1, ...array2]));
console.log(deduplicatedArray); // [1, 2, 3, 4, 5, 6, 7]
```

A `Set` stores unique values, so duplicates are removed automatically.

## 2. Frequency Map

Count occurrences with `Map<number, number>`.

```ts
const frequencyMap = new Map<number, number>();
for (const num of array1) {
  frequencyMap.set(num, (frequencyMap.get(num) || 0) + 1); // Increment count if exists, otherwise initialize to 1
}
for (const num of array2) {
  frequencyMap.set(num, (frequencyMap.get(num) || 0) + 1); // Increment count if exists, otherwise initialize to 1
}
console.log(frequencyMap); // Map(7) { 1 => 1, 2 => 1, 3 => 2, 4 => 2, 5 => 2, 6 => 1, 7 => 1 }
```

## 3. Transformations with `map`

```ts
const transformedArray = array1.map((num) => num * 2);
console.log(transformedArray); // [2, 4, 6, 8, 10]
```

## 4. Exercise: Group Users by Country

```ts
interface User {
  name: string;
  country: string;
}

const users: User[] = [
  { name: "Alice", country: "USA" },
  { name: "Bob", country: "Canada" },
  { name: "Charlie", country: "USA" },
  { name: "David", country: "UK" },
];

const usersByCountry = new Map<string, User[]>();
for (const user of users) {
  if (!usersByCountry.has(user.country)) {
    usersByCountry.set(user.country, []);
    console.log(`Added new country: ${user.country}`);
    console.log(`Current usersByCountry Map:`, usersByCountry);
  }
  usersByCountry.get(user.country)!.push(user);
  console.log(`Added user ${user.name} to country ${user.country}`);
  console.log(`Current usersByCountry Map:`, usersByCountry);
}
console.log(usersByCountry);
```

## 5. Convert Grouped Map to Other Shapes

### Map -> Object

```ts
const usersByCountryObject = Object.fromEntries(usersByCountry);
console.log(usersByCountryObject);
```

### Map -> Array of Entries

```ts
const usersByCountryArray = Array.from(usersByCountry);
console.log(usersByCountryArray);
```
