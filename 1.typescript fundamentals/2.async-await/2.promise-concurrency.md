# Promise Concurrency Methods

## Running Async Work in Parallel

JavaScript provides built-in Promise combinators for coordinating multiple asynchronous tasks.

## `Promise.all`

`Promise.all` waits for all promises to resolve.

- Resolves with ordered results when all succeed
- Rejects immediately if any input promise rejects

```ts
const Promise1 = Promise.resolve(1);
const Promise2 = Promise.resolve("Hello world");
const Promise3 = Promise.reject(new Error("Something went wrong"));

Promise.all([Promise1, Promise2])
  .then(([result1, result2]) => {
    console.log(result1); // 1
    console.log(result2); // "Hello world"
  })
  .catch((error) => {
    console.error(error);
  });

Promise.all([Promise1, Promise3])
  .then(([result1, result3]) => {
    console.log(result1);
    console.log(result3);
  })
  .catch((error) => {
    console.error(error.message); // "Something went wrong"
  });
```

## `Promise.allSettled`

`Promise.allSettled` waits for every promise to finish, regardless of success or failure.

```ts
Promise.allSettled([Promise1, Promise3]).then((results) => {
  results.forEach((result) => {
    if (result.status === "fulfilled") {
      console.log(`Fulfilled with value: ${result.value}`);
    } else {
      console.error(`Rejected with reason: ${result.reason.message}`);
    }
  });
});
```

Useful when you need all outcomes, not fail-fast behavior.

## `Promise.any`

`Promise.any` resolves as soon as the first promise resolves.

- Rejects only if all input promises reject

```ts
Promise.any([Promise1, Promise3])
  .then((result) => {
    console.log(result); // 1
  })
  .catch((error) => {
    console.error(error);
  });
```

## `Promise.race`

`Promise.race` settles as soon as the first input settles (resolve or reject).

```ts
Promise.race([Promise1, Promise3])
  .then((result) => {
    console.log(result);
  })
  .catch((error) => {
    console.error(error.message);
  });
```

## Quick Selection Guide

- Use `Promise.all` when all tasks are required.
- Use `Promise.allSettled` when you need per-task outcomes.
- Use `Promise.any` when first success wins.
- Use `Promise.race` when first completion (success/failure) wins.
