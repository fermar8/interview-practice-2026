# Basic TypeScript in React

## Why Use TypeScript in React Components

TypeScript adds type safety to React code.

You can type:

- Props
- State
- Other variables and function contracts

Benefits:

- Catch errors earlier
- Improve code quality
- Provide clearer, self-documenting component contracts

## Example: Typed State with useState

```tsx
import React, { useState } from 'react';

function Counter() {
    const [count, setCount] = useState<number>(0);

    return (
        <div>
            <p>Count: {count}</p>
            <button onClick={() => setCount(count + 1)}>Increment</button>
        </div>
    );
}
```

In this example, `count` is explicitly typed as `number` with `useState<number>(0)`.

## Example: Typed Props

```tsx
function Greeting(props: { name: string }) {
    return <h1>Hello, {props.name}!</h1>;
}
```

This defines a functional component that only accepts a `name` prop of type `string`.
