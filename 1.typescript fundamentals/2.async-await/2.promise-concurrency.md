# Promise Concurrency Methods

## Overview
JavaScript provides several methods to handle multiple promises concurrently.

## Promise.all()
Run multiple asynchronous tasks in parallel. Returns a new promise that resolves when **all** input promises have resolved, or rejects if **any** reject.

```typescript
const Promise1 = Promise.resolve(1);
const Promise2 = Promise.resolve("Hello world");
const Promise3 = Promise.reject(new Error("Something went wrong"));

Promise.all([Promise1, Promise2]).then(([result1, result2]) => {
    console.log(result1); // 1
    console.log(result2); // "Hello world"
}).catch((error) => {
    console.error(error);
});
```

### If Any Promise Rejects
If any of the promises reject, the entire `Promise.all` will reject with that error:

```typescript
Promise.all([Promise1, Promise3]).then(([result1, result3]) => {
    console.log(result1); // This will not run
}).catch((error) => {
    console.error(error.message); // "Something went wrong"
});
```

## Promise.allSettled()
Similar to `Promise.all`, but waits for **all promises to settle** (either resolve or reject) and returns an array of objects describing the outcome of each promise:

```typescript
Promise.allSettled([Promise1, Promise3]).then((results) => {
    results.forEach((result) => {
        if (result.status === "fulfilled") {
            console.log(`Fulfilled with value: ${result.value}`);
        } else {
            console.error(`Rejected with reason: ${result.reason.message}`);
        }
    });
});
```

## Promise.any()
Returns a new promise that resolves as soon as **any** of the input promises resolves, or rejects if **all** reject:

```typescript
Promise.any([Promise1, Promise3]).then((result) => {
    console.log(result); // 1, first promise to resolve
}).catch((error) => {
    console.error(error);
});
```

## Promise.race()
Returns a new promise that resolves or rejects as soon as **any** of the input promises resolves or rejects:

```typescript
Promise.race([Promise1, Promise3]).then((result) => {
    console.log(result); // 1, first promise to resolve
}).catch((error) => {
    console.error(error.message); // "Something went wrong", first promise to reject
});
```
