# Loops

## Overview
Different loop types serve different purposes in JavaScript/TypeScript.

## for Loop
A traditional loop with three parts: initialization, condition, and increment/decrement:

```typescript
const numbers2 = [1, 2, 3, 4, 5];
for (let i = 0; i < numbers2.length; i++) {
  console.log(numbers2[i]); // Output: 1 2 3 4 5
}
```

## for...of Loop
Used to iterate over iterable objects (like arrays, strings, maps, sets, etc.):

```typescript
for (const num of numbers2) {
  console.log(num); // Output: 1 2 3 4 5
}
```

## for...in Loop
Used to iterate over the enumerable properties of an object. It iterates over the **keys**, not the values:

```typescript
const obj2 = { a: 1, b: 2, c: 3 };
for (const key in obj2) {
  if (obj2.hasOwnProperty("a")) { // Check if it's an own property
    console.log(`${key}: ${obj2[key as keyof typeof obj2]}`);
    // Type assertion is used to tell TypeScript that key is a key of obj2
  } else {
    console.log(`${key} is not an own property of obj2`);
  }
}
```

## while Loop
Executes a block of code as long as a specified condition is true:

```typescript
let count = 0;
while (count < 5) {
  console.log(count); // Output: 0 1 2 3 4
  count++;
}
```

## do...while Loop
Similar to a while loop, but executes the block of code **at least once** before checking the condition:

```typescript
let count2 = 0;
do {
  console.log(count2); // Output: 0 1 2 3 4
  count2++;
} while (count2 < 5);
```

## Best Practices
- The `for...of` loop is generally preferred for iterating over arrays and other iterable objects
- The `for...in` loop is more suitable for iterating over the properties of an object
