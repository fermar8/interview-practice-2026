# Functional Components in React

## What Functional Components Are

Functional components in React are JavaScript functions that return JSX.

JSX is a syntax extension for JavaScript that looks similar to HTML.

Functional components are a simpler way to create components compared to class components.

## Props in Functional Components

Functional components can accept props as an argument.

Props are used to pass data from a parent component to a child component.

Key points:

- Props are passed as an object
- Props can be accessed using dot notation
- Props are read-only, so a component should not modify the props it receives

## Hooks in Functional Components

Functional components can use hooks.

Hooks are functions that let you use state and other React features in functional components.

## Example

```tsx
function Greeting(props: { name: string }) {
    return <h1>Hello, {props.name}!</h1>;
}
```
