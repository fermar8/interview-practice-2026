# SQL Aggregations

## Overview
Grouping rows that have the same values in specified columns into summary rows.

## GROUP BY Clause
Used to calculate aggregate values for groups of rows:

```sql
SELECT Product, Region, SUM(Amount) AS TotalSales
FROM Sales
GROUP BY Product, Region;
```

### Example Breakdown
In this example:
- Grouping sales data by both `Product` and `Region`
- Using the `SUM()` function to calculate total sales amount for each group
- Results show total sales for each product in each region

## Common Aggregate Functions
- **SUM()** – Sum of values
- **AVG()** – Average of values
- **COUNT()** – Count of rows
- **MAX()** – Maximum value
- **MIN()** – Minimum value

## Grouping by Multiple Columns
You can group by multiple columns to create more detailed summaries:

```sql
SELECT Product, Region, SUM(Amount) AS TotalSales
FROM Sales
GROUP BY Product, Region;
```

This creates a separate group for each unique combination of `Product` and `Region`.
