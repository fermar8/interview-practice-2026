# SQL Aggregations with GROUP BY

## Purpose of `GROUP BY`

`GROUP BY` groups rows that share the same values in selected columns, allowing aggregate calculations per group.

## Example

Given a `Sales` table with `Product`, `Region`, and `Amount`, calculate total sales by product and region:

```sql
SELECT Product, Region, SUM(Amount) AS TotalSales
FROM Sales
GROUP BY Product, Region;
```

## What This Produces

- One summary row per unique `(Product, Region)` pair
- `SUM(Amount)` computed for each group
