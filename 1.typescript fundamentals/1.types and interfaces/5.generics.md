# Generics

## Overview
We need a way of capturing the type of an argument in such a way that we can also use it to denote what is being returned. We use a **type variable**, a special kind of variable that works on types rather than values.

## Basic Generic Function
```typescript
function identity<Type>(arg: Type): Type {
  return arg;
}
```

This `Type` allows us to capture the type the user provides (e.g., `number`) so that we can use that information later. Here, we use `Type` again as the return type.

## Calling a Generic Function

### Explicit Type Argument
```typescript
let output = identity<string>("myString");
```

### Type Argument Inference (Most Common)
```typescript
let output2 = identity("myString");
```

## When to Use Generics
You start needing a generic when:
- You truly don't know what type is going to be passed into the function
- You have things inside the function that rely on knowing that type
