# Async/Await in TypeScript

## What `async` and `await` Do

`async` marks a function as asynchronous and makes it return a promise.

`await` pauses execution inside that `async` function until a promise settles, which makes asynchronous code read more like synchronous code.

## Basic Example

```ts
function resolveAfter2Seconds(): Promise<string> {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve("resolved");
    }, 2000);
  });
}

async function asyncCall(): Promise<void> {
  console.log("calling");
  const result = await resolveAfter2Seconds();
  console.log(result);
}
```

## Sequential Async Execution

Sequential flow means task 2 starts only after task 1 finishes.

```ts
async function fetchSequentially() {
  try {
    const response1 = await fetch("https://randomuser.me/api/?results=10");
    const data1 = await response1.json();
    console.log("response fetch1", data1);

    const response2 = await fetch("https://randomuser.me/api/?results=9");
    const data2 = await response2.json();
    console.log("response fetch2", data2);
  } catch (error) {
    console.error("error fetch", error);
  }
}

fetchSequentially();
```

## Parallel Async Execution

Parallel flow starts multiple tasks at once and waits for all of them.

```ts
async function fetchInParallel() {
  try {
    const fetch1 = fetch("https://randomuser.me/api/?results=10");
    const fetch2 = fetch("https://randomuser.me/api/?results=9");

    const [response1, response2] = await Promise.all([fetch1, fetch2]);

    const data1 = await response1.json();
    const data2 = await response2.json();

    console.log("response fetch1", data1);
    console.log("response fetch2", data2);
  } catch (error) {
    console.error("error fetch", error);
  }
}

fetchInParallel();
```

## Rule of Thumb

- Use sequential execution when tasks depend on previous results.
- Use parallel execution when tasks are independent and can run concurrently.
