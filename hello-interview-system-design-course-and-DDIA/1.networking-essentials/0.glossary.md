# Glossary

## Network Layer
- **IP (Internet Protocol):** A protocol at the network layer responsible for addressing and routing packets across networks.
- **DHCP (Dynamic Host Configuration Protocol):** A network management protocol used to dynamically assign IP addresses and other network configuration parameters to devices on a network.

## Transport Layer
- **TCP (Transmission Control Protocol):** A transport layer protocol that provides reliable, ordered, and error-checked delivery of data between applications.
- **UDP (User Datagram Protocol):** A transport layer protocol that provides a simpler, connectionless communication model with minimal overhead, but without guarantees for delivery, ordering, or error checking.
- **QUIC:** A transport layer protocol designed to provide security and performance improvements over TCP, often used for HTTP/3.

## Application Layer - HTTP Variants
- **HTTP (Hypertext Transfer Protocol):** An application layer protocol used for transmitting hypermedia documents, such as HTML, over the web.
- **HTTPS:** Secure version of HTTP with TLS/SSL encryption.
- **HTTP/2:** An updated version of HTTP that introduces features like multiplexing, header compression, and server push to improve performance.
- **HTTP/3:** The latest version of HTTP, built on top of QUIC, providing improved performance and security over HTTP/2.

## Application Layer - Other Protocols
- **DNS (Domain Name System):** An application layer protocol that translates human-readable domain names into IP addresses.
- **WebSockets:** An application layer protocol providing full-duplex communication channels over a single TCP connection.
- **WebRTC:** An application layer protocol enabling real-time communication (audio, video, and data) directly between browsers and devices.

## API Paradigms
- **REST (Representational State Transfer):** An architectural style for designing networked applications, relying on stateless communication and standard HTTP methods.
- **GraphQL:** An API query language and runtime that allows clients to request exactly the data they need from a server, reducing over-fetching and under-fetching of data.
- **gRPC (gRPC Remote Procedure Call):** A high-performance RPC framework from Google that uses HTTP/2 and Protocol Buffers for efficient communication between services.

## NAT Traversal
- **NAT (Network Address Translation):** A technique used by routers to map private IP addresses within a local network to a single public IP address, allowing multiple devices to share a single public IP and facilitating communication with external networks.
- **STUN (Session Traversal Utilities for NAT):** A protocol that allows clients behind NAT to discover their public IP address and port, facilitating peer-to-peer communication.
- **TURN (Traversal Using Relays around NAT):** A protocol that relays traffic through a central server to enable communication between peers behind NAT when direct peer-to-peer communication is not possible.

## Internet Infrastructure
- **ISP (Internet Service Provider):** A company that provides individuals and organizations access to the Internet and other related services.
- **Backbone Provider:** A company that operates the high-capacity networks forming the core of the Internet, connecting ISPs and large networks together.
- **RIR (Regional Internet Registry):** An organization responsible for allocating and managing IP address resources within a specific region of the world.
