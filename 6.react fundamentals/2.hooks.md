# React Hooks

## Component and Hook Basics

A component renders UI and can have state and side effects.

Hooks are functions that let you hook into React features from functional components, so you can use things like state and side effects without writing class components.

## useState

`useState` is a hook for adding state to a functional component.

It returns:

- The current state value
- A function to update that state

Important behavior:

- Updating state with the setter triggers a re-render
- Do not mutate state directly
- Always use the setter so React can track updates correctly

### Example: Counter

```tsx
import { useState } from 'react';

function Counter() {
    const [count, setCount] = useState(0);

    const increment = () => setCount(count + 1);
    const decrement = () => setCount(count - 1);

    return (
        <div>
            <p>Count: {count}</p>
            <button onClick={increment}>Increment</button>
            <button onClick={decrement}>Decrement</button>
        </div>
    );
}
```

## useEffect

`useEffect` lets you perform side effects in functional components.

It takes a function that runs after render.

Common side effects include:

- Fetching data
- Setting up subscriptions
- Manually interacting with the DOM

Cleanup:

- Return a cleanup function from the effect when needed
- Cleanup prevents issues like memory leaks

Dependency array behavior:

- `[]`: run once on mount
- `[count]`: run whenever `count` changes

### Example: Timer

```tsx
import { useEffect } from 'react';

function Timer() {
    const [seconds, setSeconds] = useState(0);

    useEffect(() => {
        const interval = setInterval(() => {
            setSeconds(prevSeconds => prevSeconds + 1);
        }, 1000);

        return () => clearInterval(interval);
    }, []);

    return <p>Seconds: {seconds}</p>;
}
```

Note: The empty dependency array means this effect runs once when the component mounts.

## useContext

`useContext` lets a functional component read a context value.

It takes a context object created by `React.createContext` and returns the current value.

### Example

```tsx
import { useContext } from 'react';

const ThemeContext = React.createContext('light');

function ThemedComponent() {
    const theme = useContext(ThemeContext);
    return <p>Current theme: {theme}</p>;
}
```
