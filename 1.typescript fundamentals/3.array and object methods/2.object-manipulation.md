# Object Manipulation

## Overview
JavaScript/TypeScript provides several static methods for manipulating objects.

## Object.assign()
Copies the values of all enumerable own properties from one or more source objects to a target object. Returns the target object.

```typescript
const target = { a: 1, b: 2 };
const source = { b: 4, c: 5 };
const returnedTarget = Object.assign(target, source);

console.log(returnedTarget); // Output: { a: 1, b: 4, c: 5 }
```

## Object.keys()
Returns an array of a given object's own enumerable property names:

```typescript
const obj = { a: 1, b: 2, c: 3 };
const keys: string[] = Object.keys(obj);
console.log(keys); // Output: ["a", "b", "c"]
```

## Object.values()
Returns an array of a given object's own enumerable property values:

```typescript
const values: number[] = Object.values(obj);
console.log(values); // Output: [1, 2, 3]
```

## Object.entries()
Returns an array of a given object's own enumerable string-keyed property `[key, value]` pairs:

```typescript
const entries: [string, number][] = Object.entries(obj);
console.log(entries); // Output: [["a", 1], ["b", 2], ["c", 3]]
```

## Object.freeze()
Freezes an object. A frozen object can no longer be changed; freezing an object prevents:
- New properties from being added
- Existing properties from being removed
- Existing properties from being changed

Essentially the object becomes effectively **immutable**:

```typescript
const frozenObj = Object.freeze({ a: 1, b: 2 });
frozenObj.a = 3; // This will not change the value of a
console.log(frozenObj); // Output: { a: 1, b: 2 }
```
