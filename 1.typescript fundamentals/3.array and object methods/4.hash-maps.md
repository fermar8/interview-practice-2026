# Hash Maps in TypeScript

## What a Hash Map Is

A hash map stores key-value pairs and is also called a hash table or dictionary in other languages.

In JavaScript/TypeScript, the built-in `Map` object provides this behavior.

## Why `Map`

`Map` allows:

- Keys of any type
- Values of any type
- Convenient APIs for add, read, check, and delete operations

## Basic Example

```ts
const myMap = new Map<string, number>();
myMap.set("one", 1);
myMap.set("two", 2);
myMap.set("three", 3);

console.log(myMap.get("two")); // 2
console.log(myMap.has("three")); // true
myMap.delete("one");
console.log(myMap.has("one")); // false
```

## `Map` vs Plain Object

Use `Map` when you need:

- Preserved insertion order
- Non-string keys
- Cleaner semantics for frequent insert/lookups/deletes
- Large key-value collections

The hash-based lookup model is generally efficient for insert and retrieval operations.

## Hash Function (Concept)

A hash function maps an input key into a fixed-size representation used to determine storage/lookup location.
