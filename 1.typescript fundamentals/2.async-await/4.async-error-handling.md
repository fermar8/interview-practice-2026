# Async Error Handling

## Error Handling with Promises (`.catch`)

In promise chains, errors are handled with `.catch`.

```ts
const aPromise: Promise<string> = new Promise((resolve, reject) => {
  setTimeout(() => {
    reject(new Error("Something went wrong!"));
  }, 1000);
});

aPromise
  .then((message) => {
    console.log(message);
  })
  .catch((error) => {
    console.error("Caught an error:", error.message);
  });
```

Any rejection in the chain is handled by the nearest `.catch`.

## Error Handling with `async/await` (`try/catch`)

With `async/await`, use `try/catch` around awaited operations.

```ts
async function asyncFunctionExample(): Promise<void> {
  try {
    const result = await aPromise;
    console.log(result);
  } catch (error) {
    console.error("Caught an error in async function:", (error as Error).message);
  }
}
```

## Practical Guidance

- Promise chains: `.catch`
- Async functions: `try/catch`
- Prefer consistent patterns per codebase for readability
