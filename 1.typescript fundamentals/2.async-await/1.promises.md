# Promises

## Overview
A **promise** represents the eventual result of an asynchronous operation. It can resolve successfully with a value or reject with an error. TypeScript enhances this by letting you declare what type of value the promise will return.

## Basic Promise
```typescript
const myPromise: Promise<string> = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve("Hello, world!");
  }, 1000);
});

myPromise.then((message) => {
  console.log(message); // TypeScript knows that message is a string
}).catch((error) => {
  console.error(error);
});
```

## Promise States
A promise has three states:

1. **Pending** – the operation is still running
2. **Fulfilled** – the operation succeeded
3. **Rejected** – the operation failed

## Resolving and Rejecting
```typescript
const getAgeOver18 = (): Promise<number> => {
    return new Promise((resolve, reject) => {
        const age = Math.floor(Math.random() * 100);
        if (age >= 18) {
            resolve(age); // The promise is fulfilled with the age value
        } else {
            reject(new Error("Underage")); // The promise is rejected with an error
        }
    });
};

getAgeOver18().then((age) => {
    console.log(`You are ${age} years old.`);
}).catch((error) => {
    console.error(error.message);
});
```

## Best Practices
**Always use `new Error()` when calling reject:**
- It preserves the stack trace, making debugging much easier
