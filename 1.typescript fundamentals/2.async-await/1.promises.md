# Promises in TypeScript

## What a Promise Represents

A promise represents the eventual result of an asynchronous operation.

A promise can:

- Resolve with a value
- Reject with an error

TypeScript adds type safety by letting you specify the resolved value type.

## Typed Promise Example

```ts
const myPromise: Promise<string> = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve("Hello, world!");
  }, 1000);
});

myPromise
  .then((message) => {
    console.log(message); // message is typed as string
  })
  .catch((error) => {
    console.error(error);
  });
```

## Promise States

A promise has three lifecycle states:

- Pending: still running
- Fulfilled: completed successfully
- Rejected: failed

## Resolve and Reject Example

```ts
const getAgeOver18 = (): Promise<number> => {
  return new Promise((resolve, reject) => {
    const age = Math.floor(Math.random() * 100);
    if (age >= 18) {
      resolve(age);
    } else {
      reject(new Error("Underage"));
    }
  });
};

getAgeOver18()
  .then((age) => {
    console.log(`You are ${age} years old.`);
  })
  .catch((error) => {
    console.error(error.message);
  });
```

Use `new Error(...)` when rejecting so stack traces stay useful for debugging.
