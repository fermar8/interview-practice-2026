# Bit Manipulation

Bit manipulation is a concept in computer science that lets us perform fast operations directly on the binary representation of numbers. It is not really a data structure or algorithm by itself, but a powerful technique that can simplify problems and improve time complexity in certain cases.

This topic is not always the most common in coding interviews, but it is still useful in many areas of programming and system design.

Recall from the earlier chapter on bits: a bit is the smallest unit of data a computer uses to represent information.

Let us look at how bits can help us solve algorithmic problems.

---

## Truth tables and bit operations

With bits, we can perform the following operations:

- AND: both bits must be `1` to produce `1`; otherwise, the result is `0`
- OR: if at least one bit is `1`, the result is `1`
- XOR: the result is `1` only when exactly one of the bits is `1`
- NOT: flips the bit (`0` becomes `1`, `1` becomes `0`)
- Bit shifting: moves bits left or right by one or more positions

### Operator summary

- `&` → AND
- `|` → OR
- `^` → XOR
- `~` → NOT
- `<<` → left shift
- `>>` → right shift

Shifting a number left by 1 is the same as multiplying it by 2. Shifting right by 1 is the same as dividing by 2.

![Bit operations](images/bit_operations.png)

To demonstrate these ideas, let us take `001`, which represents `1` in decimal.

```js
001 << 1 = 010
010 << 1 = 100
100 << 1 = 000
```

When we shift left repeatedly, the `1` gets pushed left and eventually gets truncated when it falls off the edge.

The following image shows how binary numbers map to decimal values and how to convert between the two representations.

![Bit operations decimals](images/bit_operations_decimals.png)

```js
// AND
let n = 1 & 1;

// OR
n = 1 | 0;

// XOR
n = 0 ^ 1;

// NOT (negation)
n = ~n;

// Bit shifting
n = 1;
n = n << 1;
n = n >> 1;
```

## Demonstration

Suppose we are asked to count the number of `1` bits in the binary representation of `23`.

We know:

```js
23 = 10111
```

To count the number of `1`s, we can keep shifting the bits to the right until we reach zero. The important question is: how do we know whether the current bit is `1`?

Recall that:

```js
1 & 1 = 1
```

So if `n & 1 === 1`, the current bit is a `1` and we increment the count.

```js
function countBits(n) {
  let count = 0;

  while (n > 0) {
    if ((n & 1) === 1) {
      count++;
    }

    n = n >> 1; // same as n / 2
  }

  return count;
}
```

### Step-by-step

```js
23 -> 10111

10111 & 00001 -> 00001   // first bit is 1
01011 & 00001 -> 00001   // second bit is 1
00101 & 00001 -> 00001   // third bit is 1
00010 & 00001 -> 00000   // bit is 0
00001 & 00001 -> 00001   // bit is 1
```

From the above operations, the count is `4`.

## Closing notes

That is the core idea behind bit manipulation. It is not always obvious at first, but once you understand the patterns, many problems become much simpler.

You either know the trick, or you do not — and bit manipulation is all about recognizing the right trick.

# Number of 1 Bits

**Difficulty:** Easy

**Topics:** Bit manipulation

**Company Tags:** None

You are given an unsigned integer `n`. Return the number of `1` bits in its binary representation.

You may assume `n` is a non-negative integer that fits within 32 bits.

## Example 1

Input:

```js
n = 00000000000000000000000000010111;
```

Output:

```js
4;
```

```js
class Solution {
  /**
   * @param {number} n - a positive integer
   * @return {number}
   */
  hammingWeight(n) {
    let count = 0;

    while (n > 0) {
      if ((n & 1) === 1) {
        count++;
      }
      n = n >> 1;
    }

    return count;
  }
}
```

### Time and space complexity

- Time complexity: $O(1)$
- Space complexity: $O(1)$

# Counting Bits

**Difficulty:** Easy

**Topics:** Bit manipulation, Brian Kernighan's algorithm

**Company Tags:** None

Given an integer `n`, count the number of `1`s in the binary representation of every number in the range `[0, n]`.

Return an array `output` where `output[i]` is the number of `1`s in the binary representation of `i`.

## Example 1

Input:

```js
n = 4;
```

Output:

```js
[0, 1, 1, 2, 1];
```

Explanation:

```js
0 --> 0
1 --> 1
2 --> 10
3 --> 11
4 --> 100
```

Constraints:

```js
0 <= n <= 1000;
```

## 1. Bit Manipulation - II

### Intuition

To count the number of `1` bits efficiently, we can use Brian Kernighan's algorithm.

The key observation is:

- `n & (n - 1)` removes the lowest set bit from `n`
- repeating this until `n` becomes `0` counts how many `1` bits are present
- this avoids checking all 32 bits for every number

### Algorithm

1. Create an array `res` of size `n + 1` initialized with `0`.
2. For each number `i` from `1` to `n`:
   - set `num = i`
   - while `num !== 0`:
     - increment `res[i]`
     - remove the lowest set bit using `num &= num - 1`
3. Return `res`.

```js
class Solution {
  /**
   * @param {number} n
   * @return {number[]}
   */
  countBits(n) {
    const res = new Array(n + 1).fill(0);

    for (let i = 1; i <= n; i++) {
      let num = i;

      while (num !== 0) {
        res[i]++;
        num &= num - 1;
      }
    }

    return res;
  }
}
```

### Time and space complexity

- Time complexity: $O(n \log n)$
- Space complexity: $O(1)$ extra space, plus $O(n)$ for the output array

# Reverse Bits

**Difficulty:** Easy

**Topics:** Bit manipulation

**Company Tags:** None

Given a 32-bit unsigned integer `n`, reverse the bits of its binary representation and return the result.

## Example 1

Input:

```js
n = 00000000000000000000000000010101;
```

Output:

```js
2818572288;
```

Explanation:

```js
10101000000000000000000000000000;
```

## 1. Bit Manipulation

### Intuition

We are given a 32-bit unsigned integer and need to reverse all its bits.

Instead of storing bits in a string or array, we can do this directly using bit manipulation:

- extract each bit from the original number starting from the least significant bit
- place that bit into the correct reversed position in the result
- repeat this for all 32 bits

This approach avoids extra memory and works efficiently at the bit level.

### Algorithm

1. Initialize `res = 0` to store the reversed number.
2. For each bit position `i` from `0` to `31`:
   - extract the `i`th bit of `n`
   - shift it to position `(31 - i)`
   - add it to `res`
3. Return `res`.

```js
class Solution {
  /**
   * @param {number} n - a positive integer
   * @return {number} - a positive integer
   */
  reverseBits(n) {
    let res = 0;

    for (let i = 0; i < 32; i++) {
      const bit = (n >>> i) & 1;
      res += bit << (31 - i);
    }

    return res >>> 0;
  }
}
```

### Time and space complexity

- Time complexity: $O(1)$
- Space complexity: $O(1)$
