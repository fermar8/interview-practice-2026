# Two Dimensional Dynamic Programming

Two-dimensional dynamic programming is used when each subproblem depends on two variables, usually a row and a column in a grid.

This pattern appears in problems like:

- unique paths
- obstacle grids
- longest common subsequence
- other state-based grid problems

The main idea is simple: if a state is reached repeatedly, compute it once, store it, and reuse it.

---

## Core idea

A 2D DP problem usually has a state like:

- `(row, col)`
- `dp[i][j]`
- current index in two strings

The final answer for a state depends on smaller states around it.

For example, in a grid:

- the answer for a cell depends on the cell below it
- and the cell to its right

This gives a recurrence such as:

$$
dp[i][j] = dp[i + 1][j] + dp[i][j + 1]
$$

For LCS, the recurrence is:

$$
dp[i][j] = \begin{cases}
1 + dp[i + 1][j + 1] & \text{if } text1[i] = text2[j] \\
\max(dp[i + 1][j], dp[i][j + 1]) & \text{otherwise}
\end{cases}
$$

## 1. Unique Paths

### Problem

Count the number of unique paths from the top-left corner to the bottom-right corner of an `m x n` grid.

You may only move:

- down
- right

### Brute force

```js
function bruteForce(r, c, rows, cols) {
  if (r === rows || c === cols) return 0;
  if (r === rows - 1 && c === cols - 1) return 1;

  return bruteForce(r + 1, c, rows, cols) + bruteForce(r, c + 1, rows, cols);
}
```

This works, but it recalculates the same cells again and again.

The complexity is exponential:

$$
O(2^{n+m})
$$

---

### Top-down memoization

```js
class Solution {
  uniquePaths(m, n) {
    const memo = Array.from({ length: m }, () => Array(n).fill(-1));

    const dfs = (i, j) => {
      if (i === m - 1 && j === n - 1) return 1;
      if (i >= m || j >= n) return 0;
      if (memo[i][j] !== -1) return memo[i][j];

      memo[i][j] = dfs(i + 1, j) + dfs(i, j + 1);
      return memo[i][j];
    };

    return dfs(0, 0);
  }
}
```

### Complexity

- time: $O(m \times n)$
- space: $O(m \times n)$

---

### Bottom-up tabulation

```js
class Solution {
  uniquePaths(m, n) {
    const dp = Array.from({ length: m + 1 }, () => Array(n + 1).fill(0));
    dp[m - 1][n - 1] = 1;

    for (let i = m - 1; i >= 0; i--) {
      for (let j = n - 1; j >= 0; j--) {
        dp[i][j] = dp[i + 1][j] + dp[i][j + 1];
      }
    }

    return dp[0][0];
  }
}
```

This is the classic 2D DP pattern: each cell depends on the one below and the one to the right.

---

### Space optimization

```js
class Solution {
  uniquePaths(m, n) {
    let row = new Array(n).fill(1);

    for (let i = 1; i < m; i++) {
      for (let j = 1; j < n; j++) {
        row[j] = row[j] + row[j - 1];
      }
    }

    return row[n - 1];
  }
}
```

- time: $O(m \times n)$
- space: $O(n)$

## 2. Unique Paths II

### Problem

Some cells may be blocked by obstacles.

A blocked cell is `1`; an empty cell is `0`.

### Top-down DP with obstacles

```js
class Solution {
  uniquePathsWithObstacles(grid) {
    const rows = grid.length;
    const cols = grid[0].length;
    const memo = Array.from({ length: rows }, () => Array(cols).fill(-1));

    const dfs = (r, c) => {
      if (r >= rows || c >= cols) return 0;
      if (grid[r][c] === 1) return 0;
      if (r === rows - 1 && c === cols - 1) return 1;
      if (memo[r][c] !== -1) return memo[r][c];

      memo[r][c] = dfs(r + 1, c) + dfs(r, c + 1);
      return memo[r][c];
    };

    return dfs(0, 0);
  }
}
```

### Bottom-up DP with obstacles

```js
class Solution {
  uniquePathsWithObstacles(grid) {
    const rows = grid.length;
    const cols = grid[0].length;

    if (grid[0][0] === 1 || grid[rows - 1][cols - 1] === 1) return 0;

    const dp = Array.from({ length: rows + 1 }, () => Array(cols + 1).fill(0));
    dp[rows - 1][cols - 1] = 1;

    for (let r = rows - 1; r >= 0; r--) {
      for (let c = cols - 1; c >= 0; c--) {
        if (grid[r][c] === 1) {
          dp[r][c] = 0;
        } else {
          dp[r][c] = dp[r + 1][c] + dp[r][c + 1];
        }
      }
    }

    return dp[0][0];
  }
}
```

### Complexity

- time: $O(m \times n)$
- space: $O(m \times n)$

or with 1D optimization:

- space: $O(n)$

## 3. Longest Common Subsequence

### Problem

Given two strings, return the length of the longest common subsequence.

A subsequence keeps order but does not need to be contiguous.

### Recurrence

If the current characters match:

$$
dp[i][j] = 1 + dp[i + 1][j + 1]
$$

Otherwise:

$$
dp[i][j] = \max(dp[i + 1][j], dp[i][j + 1])
$$

### Top-down memoized solution

```js
class Solution {
  longestCommonSubsequence(text1, text2) {
    const memo = Array.from({ length: text1.length }, () =>
      Array(text2.length).fill(-1)
    );

    const dfs = (i, j) => {
      if (i === text1.length || j === text2.length) return 0;
      if (memo[i][j] !== -1) return memo[i][j];

      if (text1[i] === text2[j]) {
        memo[i][j] = 1 + dfs(i + 1, j + 1);
      } else {
        memo[i][j] = Math.max(dfs(i + 1, j), dfs(i, j + 1));
      }

      return memo[i][j];
    };

    return dfs(0, 0);
  }
}
```

### Bottom-up solution

```js
class Solution {
  longestCommonSubsequence(text1, text2) {
    const dp = Array.from({ length: text1.length + 1 }, () =>
      Array(text2.length + 1).fill(0)
    );

    for (let i = text1.length - 1; i >= 0; i--) {
      for (let j = text2.length - 1; j >= 0; j--) {
        if (text1[i] === text2[j]) {
          dp[i][j] = 1 + dp[i + 1][j + 1];
        } else {
          dp[i][j] = Math.max(dp[i + 1][j], dp[i][j + 1]);
        }
      }
    }

    return dp[0][0];
  }
}
```

### Complexity

- time: $O(m \times n)$
- space: $O(m \times n)$

---

## Final takeaway

Two-dimensional dynamic programming is about tracking state in a grid or across two indices.

The usual pattern is:

1. define `dp[i][j]` clearly
2. identify the transition
3. handle the base case
4. choose top-down or bottom-up
5. optimize space if possible

The underlying idea is always the same: solve smaller subproblems first, cache the results, and build the answer from there.
