# Narrowing in TypeScript

## What Narrowing Is

Sometimes a value can be one of multiple types (a union). Narrowing is how TypeScript and your runtime checks work together to identify the specific type in a code path.

## Example Problem

```ts
function padLeft(padding: number | string, input: string): string {
  return " ".repeat(padding) + input;
}
```

This fails because `padding` might be `string`, and `repeat` expects a `number`.

## Type Guard with `typeof`

```ts
function padLeftWorking(padding: number | string, input: string): string {
  if (typeof padding === "number") {
    return " ".repeat(padding) + input;
  }
  return padding + input;
}
```

## Truthiness Narrowing

```ts
function getUsersOnlineMessage(numUsersOnline: number) {
  if (numUsersOnline) {
    return `There are ${numUsersOnline} online now!`;
  }
  return "Nobody's here. :(";
}
```

A truthy/falsy check can narrow possible runtime states.

## Equality Narrowing

```ts
function exampleEqualityNarrowing(x: string | number, y: string | boolean) {
  if (x === y) {
    // Here x and y must share a compatible type branch
  }
}
```

## `in` Operator Narrowing

```ts
type Fish = { swim: () => void };
type Bird = { fly: () => void };

function move(animal: Fish | Bird) {
  if ("swim" in animal) {
    return animal.swim();
  }
  return animal.fly();
}
```

## `instanceof` Narrowing

```ts
function logValue(x: Date | string) {
  if (x instanceof Date) {
    console.log(x.toUTCString());
  } else {
    console.log(x.toUpperCase());
  }
}
```

## Practical Takeaway

Narrowing makes union types practical and safe by pairing runtime checks with compile-time type refinement.
