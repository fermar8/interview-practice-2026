# SQL Joins: Inner vs Left

## Inner Join

An `INNER JOIN` returns only rows with matching values in both tables.

Example: get customers who have orders.

```sql
SELECT Customers.CustomerName, Orders.OrderID
FROM Customers
INNER JOIN Orders ON Customers.CustomerID = Orders.CustomerID;
```

## Left Join

A `LEFT JOIN` (left outer join) returns:

- All rows from the left table
- Matching rows from the right table
- `NULL` values for right-table columns when no match exists

Example: include all customers, even those without orders.

```sql
SELECT Customers.CustomerName, Orders.OrderID
FROM Customers
LEFT JOIN Orders ON Customers.CustomerID = Orders.CustomerID;
```

## Why Rows Can Look "Missing"

With `LEFT JOIN`, left-side rows are still present even without right-side matches, but right-side fields appear as `NULL`.

This is expected behavior, not data loss.
