# Generics in TypeScript

## Why Generics Exist

Generics let you capture and reuse type information instead of hard-coding one concrete type.

You use a type variable to express relationships between input and output types.

## Identity Function Example

```ts
function identity<Type>(arg: Type): Type {
  return arg;
}
```

This means:

- Input can be any type
- Output will be the same type as input

## Calling a Generic Function

### Explicit type argument

```ts
let output = identity<string>("myString");
```

### Type argument inference (common)

```ts
let output2 = identity("myString");
```

TypeScript infers `Type` as `string` from the argument.

## When to Reach for Generics

Generics are useful when:

- You do not know the concrete type in advance
- Logic must preserve or depend on the caller-provided type
- You want reusable, type-safe abstractions
