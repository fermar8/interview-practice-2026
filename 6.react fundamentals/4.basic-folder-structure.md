# Basic React Folder Structure

## Why Structure Matters

A clear folder structure helps keep a React project organized and easier to maintain as it grows.

## Common Structure

A basic structure can look like this:

```text
src/
  components/   # reusable UI components
  pages/        # route-level page components
  hooks/        # custom hooks with reusable logic
  utils/        # utility helpers
  App.tsx       # main application component
  index.tsx     # application entry point
```

This layout keeps related files together and makes navigation easier.

## Optional Folders

Depending on project needs, you can add:

- `assets/`: images, stylesheets, and other static files
- `context/`: context providers and related files for React Context state management
- `services/`: API clients, network requests, and other service-layer logic
