# Types of Types in TypeScript

## Why `type` Aliases Are Flexible

Type aliases can represent constructs that interfaces cannot directly represent.

Examples include:

- Union types
- Intersection types
- Tuple types

## Examples

```ts
type StringOrNumber = number | string;
// Union: value can be one of the listed types

type Cat = { purrs: boolean } & { colour: string };
// Intersection: value must satisfy all combined types

type Point = [number, number];
// Tuple: fixed-length array with known element types by index
```

## Quick Summary

Use `type` when you need to model:

- Either/or values (`A | B`)
- Combined shapes (`A & B`)
- Positional structures (`[T1, T2, ...]`)
